# np-Expense-Tracker
A Python-based Expense Tracker application to manage daily expenses, track spending, organize transactions by category, and generate expense reports using JSON for persistent data storage.

💰 Personal Expense Tracker

A command-line based Personal Expense Tracker built using Python. It helps users manage their daily expenses, organize transactions, monitor spending habits, and generate expense reports.

🚀 Features

- Add Expenses: Record daily expenses with amount, category, date, and description.
- View Expenses: Display all recorded transactions.
- Search Expenses: Find specific expenses.
- Update Expenses: Modify existing expense records.
- Delete Expenses: Remove unwanted transactions.
- Total Expenses: Calculate total spending.
- Category-wise Report: Analyze expenses based on categories.
- Monthly Report: Track monthly spending.
- Highest Expense: Find the most expensive transaction.
- Data Persistence: Store expense records using JSON.

🛠️ Technologies Used

- Python 3
- JSON
- Datetime
- Object-Oriented Programming
- File Handling
- Exception Handling


⚙️ Installation & Setup

1. Clone the repository

git clone YOUR_REPOSITORY_URL

2. Navigate to the project directory

cd Expense-Tracker

3. Run the application

python main.py
